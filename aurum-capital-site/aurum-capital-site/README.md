# Aurum Capital — site estático

## Publicar no GitHub + Vercel

1. Extraia este ZIP.
2. Envie `index.html` e `README.md` para a raiz de um repositório GitHub.
3. Na Vercel, importe esse repositório.
4. Como é um site HTML/CSS/JavaScript estático, não precisa de comando de build nem de instalação. Deixe o diretório raiz como `./`.

## Antes de publicar para clientes

Este arquivo veio do material enviado e mantém os dados de demonstração. Troque o WhatsApp de exemplo (`5511999999999`), revise as estatísticas e depoimentos demonstrativos e configure o formulário de contato e o login para um serviço real. No estado atual, o formulário apenas mostra uma mensagem de sucesso e o login é uma demonstração; eles não enviam nem autenticam dados em um servidor.
